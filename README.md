# Skyblock des amis

Le serveur Skyblock entre amis. Ce dépôt contient seulement le paquet de mises à jour (le mod compilé et sa liste au
format [packwiz](https://packwiz.infra.link)) et le lanceur compilé. Pas de code source.

## Pour jouer (Windows)

Il faut un compte **Minecraft Java Edition** acheté.

1. Télécharger le lanceur :
   **[Skyblock-des-amis-Setup.exe](https://github.com/Iphrowar/skyblock-amis/releases/latest)** (page « Releases »,
   fichier `.exe`).
2. L'ouvrir. Si Windows affiche « Windows a protégé votre ordinateur » (le lanceur n'est pas signé) : cliquer sur
   **« Informations complémentaires »**, puis **« Exécuter quand même »**.
3. Cliquer sur **« Se connecter avec Microsoft »** et se connecter avec le compte qui possède Minecraft.
4. Cliquer sur **« Jouer »**. La première fois, le lanceur télécharge Java, le jeu et le mod (environ 720 Mo), puis
   entre directement sur le serveur. Ensuite, il se met à jour tout seul.

## Autre façon : Prism Launcher

Installer [Prism Launcher](https://prismlauncher.org), s'y connecter avec son compte Microsoft, puis « Ajouter une
instance » → « Importer » et coller le lien du fichier `Skyblock-des-amis.zip` de ce dépôt (bouton « Raw »).
