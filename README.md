# Skyblock des amis — paquet de mises à jour

Ce dépôt contient seulement le paquet du serveur Skyblock des amis : le mod compilé et sa liste au format
[packwiz](https://packwiz.infra.link). Pas de code source.

**Pour jouer** : installer [Prism Launcher](https://prismlauncher.org), se connecter avec son compte Microsoft
(Minecraft Java acheté), puis « Ajouter une instance » → « Importer » et coller le lien du fichier
`Skyblock-des-amis.zip` de ce dépôt (bouton « Raw »). Le jeu se met à jour tout seul à chaque lancement.
